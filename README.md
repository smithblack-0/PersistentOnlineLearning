# PersistentOnlineLearning

Research toward models that are architecturally and procedurally primed to keep learning online from an indefinitely long inference stream.

The project is not defined by a single transfer test or model architecture. The central question is whether a model can continuously infer, retain, revise, and use new rules without ordinary weight updates and without retaining an ever-growing token history.

## Current direction

The present working direction combines:

- fully recurrent DeltaNet-family causal language models;
- procedural pretraining on independently resampled synthetic languages;
- random context-free grammar topology generated by a consistent literature method;
- a downstream lexical adapter from grammar terminal categories to a normal vocabulary; and
- epsilon-machine state that later conditions production probabilities and advances only when a terminal is emitted.

Acquiring an unseen natural language during frozen-weight inference is a high-value eventual test of the capability, not the immediate implementation milestone.

## Repository stage

This repository is in preliminary research and design. The exact random CFG constructor is implemented, while the lexical adapter, state-conditioned probabilities, derivation runtime, curriculum, and integrated training system remain downstream work.

Project-wide procedures live under [`documents/procedures/`](documents/procedures/). Short LLM-specific routing and failure warnings live under [`documents/llms/`](documents/llms/). Human-facing operating instructions belong under [`documents/usage/`](documents/usage/) as runnable systems are added.
