# Repository instructions for coding and research agents

For substantial research, experiment design, engineering, review, or documentation work, read [`documents/llm/README.md`](documents/llm/README.md) before acting.

[`STATUS.md`](STATUS.md) is shared project documentation written for humans and tools. It describes the repository's latest durable position, but it is not an instruction queue and does not establish the user's current objective. When a request asks to continue earlier work without identifying the task, read `STATUS.md`, inspect live repository state, and ask the user to confirm what should be resumed.

Follow the authority, change-control, research, engineering, and writing rules linked from `documents/llm/README.md`.

Do not merge pull requests, modify CI or workflow files, change the central scientific interpretation, or promote a preliminary hypothesis into an accepted design without explicit authorization.
