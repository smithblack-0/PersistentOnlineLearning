# Preliminary Work

This folder contains early research notes, design sketches, and unresolved discussion. The files are intended to preserve the reasoning state without pretending that the design is finalized.

## Contents

- [`research_program.md`](research_program.md): the objective, current hypothesis, and scope of the research program.
- [`generator_design.md`](generator_design.md): the current procedural-generator direction and competing alternatives.
- [`model_architecture.md`](model_architecture.md): the current fully recurrent DeltaNet-family architecture direction.
- [`open_questions.md`](open_questions.md): unresolved questions that should guide the next research and design passes.

These notes should be revised as evidence changes. Rejected or superseded ideas should be recorded with the reason they were displaced rather than silently removed when that history remains useful.
