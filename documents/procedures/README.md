# Project procedures

This directory contains reusable project-wide procedures. They apply to humans and automated contributors alike and do not describe the current assignment.

- [`research_workflow.md`](research_workflow.md) — scientific exploration, experiment design, evidence review, and interpretation
- [`senior_engineering_workflow.md`](senior_engineering_workflow.md) — substantial design, implementation, debugging, and review
- [`technical_writing_workflow.md`](technical_writing_workflow.md) — execution loop for substantial documentation
- [`technical_writing_standards.md`](technical_writing_standards.md) — detailed writing evaluation criteria
- [`checkpointing.md`](checkpointing.md) — checkpoint authority, atomic local saves, bucket synchronization, and credential boundaries
